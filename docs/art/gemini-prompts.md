# YGT2025 · 제미나이 에셋 프롬프트 모음

기존 캐릭터 시트(`reference/Gemini_Generated_Image_...png`)를 **기준**으로, 게임에 필요한 나머지 에셋을 전부 뽑기 위한 프롬프트 모음이다.
전부 "엄마는 게임을 숨겼다" 톤(굵은 검정 외곽선 · 플랫 셀 채색 · 사람 비율)으로 통일한다.

---

## 0. 사용법 (중요)

1. **매 생성 때 캐릭터 시트 이미지를 같이 첨부**하고, 아래 **[공통 지시]**를 프롬프트 맨 앞에 붙인다. → 그래야 같은 캐릭터·화풍이 유지된다.
2. 각 항목 프롬프트는 **[공통 지시] 뒤에 이어 붙이면** 된다.
3. 캐릭터/소품 = **배경 투명 PNG**, 배경 씬 = **꽉 찬 세로 이미지(텍스트 없음)**.
4. 캐릭터는 **발끝을 캔버스 같은 높이**에 두고 **정중앙**에 그려달라고 요청(자세만 바뀌어도 게임에서 안 흔들림).

### [공통 지시] — 캐릭터/자세/표정용 (맨 앞에 붙이기)
```
첨부한 캐릭터 시트와 완전히 동일한 인물·화풍을 유지해.
- 화풍: 굵고 균일한 검정 외곽선, 플랫 셀 채색 + 약한 부드러운 음영, 사람 비율(약 6등신)의 한국 캐주얼 게임 일러스트, "엄마는 게임을 숨겼다" 톤.
- 복장: 공군사관학교 하계 근무복 — 흰색 반팔 셔츠(오픈 칼라, 앞단추, 가슴주머니 2개 플랩), 오른쪽 가슴 남색 명찰, 왼쪽 가슴 약장(리본 바)+은색 윙 배지, 남색 정모(검정 챙+은색 독수리 휘장), 남색 정장바지(가운데 주름), 검정 벨트(은색 버클), 검정 단화.
- 계급 표시는 어깨 견장 줄 수로만 구분: 후배(1학년)=1줄, 주인공 기태·동기(2학년)=2줄, 선배(3학년)=3줄. (설명 문구/라벨/텍스트는 이미지에 넣지 마.)
- 출력: 단일 인물, 전신, 정면 또는 살짝 3/4, 배경 완전 투명 PNG, 바닥 그림자 아주 옅게, 워터마크·글자 없음. 인물은 캔버스 정중앙, 발끝을 하단 같은 높이에 맞춤.
```

### [공통 지시 — 배경] (배경 씬용, 맨 앞에 붙이기)
```
"엄마는 게임을 숨겼다" 톤의 배경 일러스트를 그려. 굵은 검정 외곽선, 플랫 셀 채색, 약한 음영.
- 인물·캐릭터·UI·글자 없음. 텅 빈 무대(배경)만.
- 세로 구도(9:19.5), 모바일 세로화면 꽉 채움. 원근은 정면 무대형(약한 원근).
```

## 1. 표정 (추가분) — 헤드/버스트 시트

시트에 이미 있는 것(Default·Broad Smile·Serious·Nervous·Surprised·Determinate)은 **재사용**. 아래는 **게임에 필요한데 빠진 표정**들. 한 장에 모아 시트로 뽑으면 좋다.

```
[공통 지시] +
같은 인물의 얼굴(정모 포함, 어깨까지 버스트)만 아래 표정으로 각각 그려서 한 장의 표정 시트로 정리해. 배경 투명, 표정마다 살짝 간격:
1) 흥얼거림 — 눈을 지그시 감고 기분 좋게 콧노래, 입가 미소, 머리 위 음표 하나
2) 숨참기 — 입을 꾹 다물고 볼을 살짝 부풀린 채 긴장, 눈은 옆을 살핌
3) 군침/배고픔 — 눈을 반짝이며 입맛 다시는 표정(살짝 벌린 입, 침 한 방울)
4) 만족/냠 — 눈을 감고 흐뭇하게 웃으며 볼이 발그레
5) 탈진/어지러움 — 반쯤 풀린 눈(소용돌이 느낌), 지쳐 헥헥, 이마에 땀
6) 능글/장난 — 한쪽 입꼬리만 올린 개구진 미소, 눈웃음
7) 무표정/체념 — 감정 없는 데드팬, 반쯤 감긴 눈
8) 안도 — 가슴 쓸어내리듯 안심하는 부드러운 미소, 이마에 땀 한 방울
9) 곁눈 감시 — 고개는 정면인데 눈만 옆으로 매섭게(선배 감시용, 진지)
```

> 팁: 게임에선 이 표정들을 상황마다 바꿔 끼운다. 표정만 따로(버스트)로 받아두면 여러 자세에 재활용 가능.

## 2. 주인공(기태, 2학년) 자세 — 하근무복

각 자세를 **개별 투명 PNG**로. 발끝 하단 정렬·정중앙.
시트에 이미 있는 **차렷(Attention)·경례(Salute)·달리기(Running)·손흔들기(Greeting)** 는 재사용 가능.

| # | 파일명(제안) | 프롬프트에 넣을 자세 설명 |
|---|---|---|
| 1 | `player_idle` | 차렷 자세로 정면을 보고 가만히 서 있음, 자신감 있는 옅은 미소 (※시트 Attention 재활용 가능) |
| 2 | `player_walk_a` | 자연스럽게 걷는 중 — 왼발 앞, 팔 가볍게 반대로 스윙 |
| 3 | `player_walk_b` | 걷는 중 반대 프레임 — 오른발 앞 (walk_a와 세트로 2프레임) |
| 4 | `player_run` | 힘차게 구보(달리기), 이 악물고 팔 크게 저음 (※시트 Running 재활용 가능) |
| 5 | `player_dance` | 남몰래 신나서 리듬 타는 은밀한 막춤 — 어깨 들썩, 눈 감고 흥얼, 주변에 음표 |
| 6 | `player_salute` | 절도 있는 거수경례, 진지한 표정 (※시트 Salute 재활용 가능) |
| 7 | `player_cheer` | 두 팔을 번쩍 들고 환하게 환호(성공 세리머니), 주변에 반짝임 |
| 8 | `player_lying` | **옆에서 본** 침대에 반듯이 누운 자세(머리 왼쪽), 이불로 하반신 덮음, 지루한 표정 |
| 9 | `player_lying_punch` | 옆에서 본 누운 자세로 **왼쪽 벽을 주먹으로 쾅 치는** 순간, 팔을 뻗음, 긴장한 표정 |
| 10 | `player_exhausted` | 무릎에 손 짚고 허리 숙여 헥헥대는 탈진 포즈, 땀 |
| 11 | `player_sneak` | 몸을 웅크리고 살금살금 숨는 포즈(고개 움츠림), 조마조마한 표정 |

**예시 프롬프트 (자세 1개씩):**
```
[공통 지시] +
자세: 남몰래 신나서 리듬을 타는 은밀한 막춤 — 어깨를 들썩이고 눈을 감은 채 콧노래, 주변에 음표 몇 개. 전신, 정면, 투명 배경.
```

> 걷기/달리기처럼 **반복 동작**은 위 walk_a/walk_b처럼 2프레임을 받아두면 게임에서 번갈아 재생해 애니메이션이 된다. (1프레임만 있어도 흔들림 연출로 대체 가능)

## 3. 주인공 — 태권도 도복 버전 (Q4 달리기용)

필요 자세: (a) 도복 차림 걷기, (b) 도복 차림 힘찬 달리기(구보). 각각 개별 투명 PNG.

## 4. 조연 — 선배 / 후배 / 동기

같은 인물 베이스에 **얼굴·계급(견장 줄 수)·분위기만** 다르게. 각 개별 투명 PNG.

### 선배 (3학년, 견장 3줄 · 위압감)
```
[공통 지시] +
같은 화풍의 다른 인물: 공사 3학년 선배. 견장 3줄, 체격이 조금 더 크고 눈매가 날카로움(위압감). 왼팔에 빨강+흰 완장.
필요 자세:
1) senior_idle — 팔짱 끼거나 뒷짐 지고 매섭게 감시하며 서 있음 (진지/무서움)
2) senior_run — 화가 나서 이쪽으로 성큼성큼 달려옴 (분노, 입 벌려 호통)
3) senior_point — "일로 와봐" 하듯 손가락으로 가리키며 노려봄
```

### 후배 (1학년, 견장 1줄 · 앳됨)
```
[공통 지시] +
같은 화풍의 다른 인물: 공사 1학년 후배. 견장 1줄, 앳되고 긴장한 인상.
필요 자세:
1) junior_salute — 절도 있게 거수경례하며 우렁차게 "필승!" 외치는 순간 (경직, 진지)
2) junior_walk — 조심스럽게 걸어오는 모습
```

### 동기 (2학년, 견장 2줄 · 편안)
```
[공통 지시] +
같은 화풍의 다른 인물(주인공과 다른 얼굴): 공사 2학년 동기. 견장 2줄, 편안하고 친근한 인상.
필요 자세:
1) peer_idle — 편하게 서서 반응을 기다림 (무심/여유)
2) peer_walk — 대충 걸어오는 모습
```

> **복도 판별 게임(Q2)** 은 "견장 줄 수만" 단서다. 후배/동기/선배를 **같은 근무복·같은 포즈(걷기)** 로 그리되 **견장 줄 수만 1/2/3** 으로 다른 버전도 각각 받아두면 판별 난도 조절에 좋다. (`visitor_1line_walk`, `visitor_2line_walk`, `visitor_3line_walk`)

## 6. 소품 (개별 투명 PNG 오브젝트)

게임에서 배경 위에 얹거나 재배치한다. 각 **정면, 투명 배경, 단독**.

**실내/생활관:** `door_nameplate`(명패 달린 나무문), `locker_cabinet`(옷장/캐비닛), `bunk_bed`(2층 침대), `single_bed`(베개+각 잡힌 이불 1인 침대), `ceiling_light`(형광등), `wall_clock`(벽시계), `notice_board`(게시판+공지 종이), `fire_extinguisher`(소화기), `area_sign`(구역 명패 간판), `poster_mental`("정신력" 포스터), `floor_lamp`(스탠드 조명)

**샤워/세탁/취사:** `shower_head`(샤워기 헤드+파이프+밸브), `shower_stall`(부스 칸막이+커튼), `drain`(바닥 배수구), `washer`(드럼 세탁기), `microwave`(전자레인지), `counter`(조리대+수납장), `detergent_bottles`(세제통 3~4개), `exit_sign`(초록 비상구등)

**야외/원경:** `window_day`(주간 창문), `window_night`(달·야경 보이는 야간 창문), `tree`(나무), `bush`(수풀), `flagpole`(국기게양대+태극기), `barracks`(원경 생활관 건물), `mountain`(산 실루엣), `streetlight`(가로등), `cloud`(구름)

**예시 프롬프트 (소품 1개):**

오브젝트: 군용 2층 철제 침대 — 각 잡힌 모포와 흰 베개, 사다리 포함.

## 7. 미니게임 전용

### 7-1. 옷장 정리 상태 (M3 사진 고르기) — **핵심 에셋**
같은 옷장을 **정상 1장 + 흠집 4장**, 완전히 같은 구도/크기로. (틀린그림찾기용이라 정렬·크기 일치가 중요)
```
정면에서 본 군용 옷장(캐비닛) 한 장을 "엄마는 게임을 숨겼다" 톤(굵은 검정선, 플랫 채색)으로, 배경 투명 PNG, 글자 없음, 항상 같은 구도·크기로:
- 상단 칸: 각 잡아 개어 쌓은 모포 3장
- 중단 칸: 옷걸이 봉에 근무복/정복 2벌 반듯이 걸림
- 하단 칸: 닫힌 서랍(손잡이)
아래 5가지 버전을 각각:
1) locker_ok — 완벽하게 정리된 정상 상태
2) locker_tilt — 맨 위 모포 한 장만 삐뚤게 기울어짐
3) locker_drawer — 하단 서랍이 튀어나와 열려 있음
4) locker_sock — 서랍 근처에 흰 양말 한 짝이 삐져나옴
5) locker_hanger — 걸린 옷 한 벌이 옷걸이째 삐뚜름하게 걸림
```

### 7-2. 카톡 아바타 (버스트/원형 아이콘, 선택)

[공통 지시] 화풍으로, 원형 프로필 아이콘용 얼굴 버스트(어깨까지), 배경 투명:

## 9. 게임 이식용 기술 메모 (제미나이엔 안 넣어도 됨)

- 캐릭터: 투명 PNG, **모든 자세 같은 캔버스 크기 + 발끝 같은 y** (교체 시 안 튐). 권장 1024×1536 내외.
- walk/run은 2프레임 세트면 루프 애니로. 1프레임이면 상하 바운스+기울기 트윈으로 대체.
- 배경: 세로 9:19.5, 최소 1440px 폭(2x). Q4 도로는 **세로 타일링 이음새** 필수.
- 정면(약간 3/4) 기준. 게임은 좌우 이동 시 스프라이트를 뒤집을 수 있으니 **좌우 대칭이거나 미러링 가능한** 포즈가 유리.
- 표정은 버스트로 따로 받아두면 대사 순간마다 갈아끼우기 쉬움(몸은 idle 유지).

## 10. 2차 추가분 — 원근/뒷모습/샤워 실루엣 (8종)

원근을 살리려면 "정면 전신" 한 장으로는 부족하다. 카메라를 등지고 화면 안쪽으로
걸어가는 장면(전자레인지 앞, 무용관 가는 길)과, 옷을 벗고 씻는 장면(샤워)은
전용 컷이 필요하다.

| 키 | 내용 |
|---|---|
| `player_back_idle` | 근무복 **완전한 뒷모습**, 가만히 서 있음 (전자레인지 앞) |
| `player_hide_door` | 정면, 몸을 세로로 좁게 접어 넣고 훔쳐보는 자세 (세탁실 문 안) |
| `player_dobok_walk_back` / `_b` | 도복 뒷모습 걷기 2프레임 (팔다리 교차) |
| `player_dobok_run_back` / `_b` | 도복 뒷모습 구보 2프레임 (뒷발바닥이 보이게) |
| `player_shower` | 샤워 중 — **완전한 단색 그림자 실루엣** + 허리를 가리는 흰 수증기 띠, 리듬 타는 자세 |
| `player_shower_quiet` | 같은 실루엣, 어깨를 움츠리고 얼어붙은 자세 |

**샤워 실루엣 프롬프트의 핵심 (여러 번 실패 후 정착한 문구):**

- "몸 안쪽은 디테일 없이 짙은 남회색 **한 가지 색으로 꽉 채운다**" — 이목구비·근육을
  그리지 말라고 명시해야 노출 없는 그림자가 나온다. "실루엣"만으로는 부족했다.
- "허리에서 허벅지까지는 **두툼하고 불투명한 흰 수증기 띠**가 가로지른다"
- 수증기에는 **굵은 검정 외곽선**을 요구할 것 — 안 그러면 크로마키 플러드필이
  테두리에서 흰 김을 따라 들어가 몸통에 구멍을 뚫는다.

**뒷모습 프롬프트의 핵심:** "완전한 뒷모습(등을 보고 있음, 얼굴 안 보임, 뒤통수와
등이 카메라를 향함)" — "뒤에서 본"만 쓰면 고개를 돌려 얼굴을 그려버린다.

### 원근 배치 규칙 (코드 쪽)

발끝 y 하나로 크기가 정해지게 해야 캐릭터가 바닥에서 뜨지 않는다.
`높이 = 발끝y - 소실점y` 꼴의 1차식을 씬마다 하나 두고, 그 높이에서 스케일을 역산한다.
스프라이트는 투명 여백을 트림해 **밑변 = 발끝**이므로 그림자를 밑변에 두면 정확히 맞는다.
